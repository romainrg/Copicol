# AGENTS.md

Instructions for AI coding agents (Claude Code, Codex, GitHub Copilot, Cursor, Gemini…) working on Copicol. Humans should read [CONTRIBUTING.md](CONTRIBUTING.md); this file summarizes the same rules in an actionable form.

## Project

Copicol is a native macOS clipboard manager: a menu bar app (macOS 14+) that captures what the user copies, shows it on a shelf that slides up with ⇧⌘V, and pastes the chosen item into the previously active app. Swift 6 toolchain in Swift 5 language mode, SwiftUI with AppKit, SwiftData, sandboxed, no third-party dependencies.

## Commands

Run them from the repository root. If `xcode-select` points to the Command Line Tools, prefix them with `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`.

```sh
xcodegen generate                                # after adding/removing/renaming a file or editing project.yml
xcodebuild -project Copicol.xcodeproj -scheme Copicol -configuration Debug -derivedDataPath build build
xcodebuild test -project Copicol.xcodeproj -scheme Copicol -derivedDataPath build -destination 'platform=macOS'
swift test --package-path CopicolCore            # core tests only, faster
scripts/build-release.sh                         # universal Release build + zip in build/release/
scripts/screenshots.sh                           # regenerate docs/images from the real views
```

## Map

- `project.yml`: XcodeGen spec (targets, Debug/Release/iCloud configurations, schemes). It is the source of truth: `Copicol.xcodeproj` and `Copicol/Resources/Info.plist` are generated and git-ignored.
- `CopicolCore/Sources/CopicolCore/`: all the testable logic.
  - `Models/`: `ClipItem` (history, *Local* container), `PendingDeletion` (*Local*), `Pinboard`, `SyncedClip` and `SyncTombstone` (*Boards* container).
  - `Capture/`: `PasteboardReader` (NSPasteboard → `CapturedContent`, privacy filters), `PasteboardWriter`, `ContentClassifier` (text, link or color), `ContentHasher`, `PayloadBuilder`, `HexColor`.
  - `Storage/`: `ClipStore` (ingest, deduplication, retention, pinboards), `FileStore`, `StorageFactory`, `RetentionPolicy`.
  - `Search/ClipQuery.swift`, `Sync/CloudMirror.swift`, `Sync/CloudSyncAvailability.swift`.
- `CopicolCore/Tests/CopicolCoreTests/`: XCTest suites; shared helpers in `TestSupport.swift`.
- `Copicol/`: app target. `App/AppDelegate.swift` is the composition root; then `ClipboardMonitor/`, `HotKey/`, `PasteService/`, `ShelfUI/`, `Settings/`, `MenuBar/`, `Onboarding/`, `Resources/`.
- `Tools/Screenshots/`: offscreen renderer for the README images (development only, never shipped).
- `docs/ARCHITECTURE.md`: data flow, data model and sync design. Read it before changing storage, capture or sync.

## Invariants

Never break these. If a task seems to require it, stop and ask the human.

1. **Privacy**: never persist pasteboard content of type `org.nspasteboard.ConcealedType`, `org.nspasteboard.TransientType` or `org.nspasteboard.AutoGeneratedType`; honor `excludedBundleIDs`; never log clipboard contents; no telemetry and no new network calls.
2. **Own writes**: Copicol tags its pasteboard writes with `org.nspasteboard.source` set to its bundle identifier, and the monitor skips them. Keep both sides consistent.
3. **Sandbox and identifiers**: do not add entitlements, disable the sandbox, or change `io.github.romainrg.Copicol`, `io.github.romainrg.copicol.item-id` or `iCloud.io.github.romainrg.Copicol`.
4. **SwiftData**: *Boards* models stay CloudKit-compatible (a default value on every property, no `@Attribute(.unique)`, no relationships). Schema changes must be lightweight-migratable. `ClipItem` references its pinboard through `pinboardID`, not a relationship.
5. **Sync** (`CloudMirror`): a missing remote copy never deletes a local item; deletions propagate only through `SyncTombstone`; retention purges never propagate; `modifiedAt` changes only when pinning changes; usage dates merge by maximum. `CloudMirrorTests` encodes these rules: extend it, never weaken it.
6. **Concurrency**: `ClipStore`, view models and UI are `@MainActor`; heavy work (hashing, images) runs in detached tasks on `Sendable` values.
7. **Keyboard** (`ShelfController.handleKeyDown`): `⌫` alone never deletes an item; keys go to the search field while an input method has marked text; `⌘1`…`⌘9` use physical key codes so they work with any keyboard layout.
8. **Dependencies**: Apple frameworks only. Do not add Swift packages.

## Conventions

- Code comments and documentation comments in **French**; identifiers in **English**; user-facing strings in French (the app is not localized yet).
- MVVM with `@Observable`; no new singletons; logic in `CopicolCore`, system integration and UI in `Copicol/`.
- Zero compiler warnings; 4-space indentation; `// MARK: -` sections.
- Conventional Commits: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `perf:`, `build:`, `ci:`, `chore:`.

## Definition of done

- `xcodegen generate`, the Debug build and `xcodebuild test` succeed without new warnings.
- Logic changes have unit tests in `CopicolCoreTests`; bug fixes include a regression test.
- The shelf, the paste flow and the windows cannot be driven automatically: that requires Accessibility and Screen Recording permissions. Do not attempt UI automation or trigger permission prompts. Use `scripts/screenshots.sh` to render the shelf when it is relevant, and list the manual test steps for the human.
- User-visible changes have an entry under **Unreleased** in `CHANGELOG.md`; documentation is updated when commands, behavior or rules change.
- Do not bump versions, create tags, or edit the release workflow or signing settings unless explicitly asked.
- Pull requests follow `.github/PULL_REQUEST_TEMPLATE.md`, including the *AI assistance* section.
